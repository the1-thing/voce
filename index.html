Collega questo telefono

Si fa una volta sola. Serve una chiave di GitHub che può scrivere soltanto nella casella delle note.

  1. Apri la pagina della chiave su GitHub.
  2. In Repository access scegli Only select repositories e seleziona .
  3. Controlla che in Permissions ci sia Contents: Read and write, poi Generate token.
  4. Copia la chiave e incollala qui sotto.
